# Product Overview

## Working title
Bulgarian Grocery Price Alert App

## Core loop
Open app → see immediate price value → enter a natural-language shopping list or watchlist → resolve items → compare stores → save or alert.

## Why this MVP exists
- there is a live daily public price source
- users care about grocery prices and recent euro-era price visibility
- the product can validate itself quickly through actual usage and a small revenue stream
- longer term, the product creates a clean path into market-gap detection for real-world goods and services

## MVP principles
- anonymous-first
- two taps or less to useful value
- deterministic matching first, AI only for ambiguity
- preserve raw user intent separately from canonical matching
- make operator and legal overhead minimal

## Initial monetization
- AdMob banners and interstitials
- optional premium later for smart alerts / unlimited automation

## Longer-term intelligence goal
Create a non-creepy, aggregate, local demand-signal system that can surface gaps between what people want and what local physical markets currently provide.
