# Phase 0 — Foundation

## Objective
Create the clean starter repository, documentation system, verification scripts, and operator-handoff pattern.

## Scope
- repo structure
- docs structure
- prompt library structure
- test / decision / feature registries
- handoff templates
- verification scripts

## Out of scope
- live Firebase setup
- business logic
- production UI

## Acceptance criteria
- repo verifies with `npm run verify`
- base docs exist
- handoff template exists
- operator actions template exists
