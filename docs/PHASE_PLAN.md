# Phase Plan

## Phase 0 — Foundation
Repo scaffold, docs scaffold, conventions, verification scripts, handoff structure.

## Phase 1 — Data Backbone
Daily importer, raw row preservation, normalized price records, canonical product placeholders, fixtures.

## Phase 2 — Matching Backbone
Normalization, alias lookup, fuzzy matching, confidence scoring, selective AI escalation, cache.

## Phase 3 — Core User Flow
Shopping-list input, result computation, best-basket output, price-history display.

## Phase 4 — Saved Lists / Watchlists / Preferences
Anonymous saved lists, preferred stores, smart reminders, alert hooks.

## Phase 5 — Monetization
AdMob, premium feature flags, upgrade flow.

## Phase 6 — Market Gap Intelligence
Feedback events, unresolved-item logging, aggregate signal generation.

## Phase 7 — Deployment and Polish
Firebase deployment, device testing, release prep, visual polish.
